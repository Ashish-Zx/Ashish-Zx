## Featured Project

### 🛡️ SentinelSRE — Autonomous Incident & Root-Cause Engineering

> A single input, a single guarded output: **a stack trace in, a verified hotfix PR out.**

SentinelSRE orchestrates a parallel multi-agent **"war room"** to investigate a production incident: four specialist agents (Log Investigator, Git Historian, Runbook Agent, Security Agent) investigate independently, an Incident Commander synthesizes the root cause, an **L4 zero-history verifier** audits the proposed patch against the raw trace and source, and a **human-in-the-loop gate** blocks changes to protected paths (auth, payments, migrations) until explicit approval — then it opens a draft PR.

- **Architecture:** Next.js 16 frontend, FastAPI backend, parallel agents + synthesizer + L4 verifier
- **Stack:** TypeScript · Python · PostgreSQL with pgvector (Neon) · Cloudflare R2 · Clerk · SSE streaming
- **Provider-agnostic LLM:** Inception (mercury-3), OpenAI, or Anthropic

🔗 [View repository](https://github.com/Ashish-Zx/sentinel-sre) · 🌐 [Live demo](https://sentinelsre.live)
